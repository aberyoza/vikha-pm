# Віха — Design System (MASTER)

Global source of truth for how the site looks. Every new page, module,
lesson or component follows this file. Page-specific deviations go to
`design-system/vikha/pages/<page>.md` and override this file only for that page.

History: v1 came from the `ui-ux-pro-max` skill (Swiss minimalism, light).
v2 was designed with Anthropic's `frontend-design` skill: warm graphite,
honey, sage, graph-paper hero, dark only. v3 (current, PR #2, October 2026)
is a "taste pass": a designer said v2 obviously looked generated by Claude,
so the author asked to remove that impression. v3 borrows ideas from Emil
Kowalski's design-engineering skills, tasteskill.dev and componentry.dev and
adapts them to Віха ("90% borrowed, 10% ours"). The site itself is the
reference; `/lab` (noindex, not linked) holds ideas under evaluation.

## 1. Concept: "Віха як діаграма Ганта"

The visual language comes from project management itself: Gantt bars,
milestone diamonds ◆, a "you are here" line. **One bold element per page**
(on the home page: the course program drawn as a Gantt chart); everything
around it stays quiet. Real content carries the page, not decoration.

- Audience: Ukrainian adults learning PM, beginner → advanced. Calm, practical.
- **Dark by default, light on request.** A header toggle (`ThemeToggle`)
  switches themes. The choice lives in `localStorage` (`vikha-theme`) and an
  inline script in `<head>` applies `data-theme="light"` before first paint
  (no flash, pages stay static). There is no `prefers-color-scheme` branch.
- Print, not screen: near-black ink with a trace of warmth, paper grain,
  one honey accent. Surfaces are separated by tone, not by lines.

## 2. Color tokens

Defined once in `src/app/globals.css` — `:root` (dark) and
`:root[data-theme="light"]` — and exposed to Tailwind via `@theme inline`.
**Components use tokens only — never raw hex**, so both themes work
automatically. A `light:` Tailwind variant exists for the rare
theme-specific tweak (e.g. which toggle icon shows).

| Token | Dark | Light | Use |
|---|---|---|---|
| `background` | `#121211` | `#f4f4f1` | page ground |
| `surface` | `#1a1a18` | `#fbfbf9` | one tone step up: figures, sidebar, chart |
| `surface-raised` | `#232320` | `#e9e9e4` | second step: tiles, raised areas |
| `foreground` | `#ecebe6` | `#171715` | text |
| `muted` | `#a3a29b` | `#5d5d57` | secondary text |
| `border` | `#2e2d2a` | `#dcdcd5` | real tables and form fields only |
| `grid` | `#1d1d1b` | `#e7e7e2` | chart rows and columns |
| `accent` | `#e8a33d` honey | `#835a00` mustard | the brand: primary button, open modules, diamonds, selected state |
| `accent-foreground` | `#1e1609` | `#fbfbf9` | text on accent |
| `accent-soft` | `#2a2414` | `#f3ead2` | accent tint: result panels, Callout |
| `sage` / `sage-soft` | `#8cc2a8` / `#1f3029` | `#3b735b` / `#e2efe8` | progress: "Ви тут", completed lessons |
| `risk-1..3` | warm clay ramp | warm clay ramp | ordinal scale (risk matrix) only |

All text pairs are ≥ 5:1 (checked with the WCAG formula).

Rules:
- **No assistant palette.** No cream or yellow-beige ground with rust or
  terracotta accents, no violet/indigo. That combination is what made v2 read
  as "made by Claude". The light theme is neutral paper with a mustard accent.
- One accent. Honey/mustard is the only CTA and selection color. Sage marks
  position/progress, never a button. Running text stays in full `foreground`.
- Ordinal/status colors always come with a text label or legend.
- Link-preview images (`src/app/og-card.tsx`) repeat the dark tokens as hex,
  because they render outside the page. Change them together with the tokens.

## 3. Typography

**Fixel** by MacPaw (Ukrainian typeface, SIL OFL — `src/fonts/fixel/OFL.txt`),
self-hosted via `next/font/local` in `src/fonts/index.ts`. TTF copies of two
cuts in `src/fonts/og/` exist only for the link-preview images (the image
renderer can't read woff2).

| Role | Cut | Utility |
|---|---|---|
| Headings, hero, section titles, figure leads, module names, numbers | Fixel Display 600 (500 available) | `font-display` |
| Body and UI | Fixel Text 400 / 500 / 600 | `font-sans` (default) |

Scale:
- Hero h1: 40px → `sm:text-6xl` → `lg:76px`, leading 1.02, tracking −0.03em, max 13ch
- Section heading (`<SectionHeading>`): 30 → 34px
- Lesson h1: 34px → 48px (≥640px); lesson h2: 28px — set in `.lesson-body`
- Lesson body: 17px, line-height 1.7, max line length **70ch**
- Small text: 13–15px, **sentence case**, `text-muted`

Typographic don'ts (they read as generated/templated):
- **no eyebrows:** no small label above a heading, lead or lesson title
  (figures keep their short `title` only as `aria-label`; the lesson page
  doesn't print «Урок N з M», the sidebar already shows it);
- no ALL-CAPS tracked labels, no monospace outside real code;
- no meta strings joined with middle dots («A · B · C»);
- no "→" appended to buttons/links (arrows only where they *mean* direction,
  e.g. cause → fix, axis labels, and the prev/next lesson cards);
- no styled accent word inside a headline. **One exception:** the hand-drawn
  marker under «віхи» in the home hero (brand word, drawn once, see §7).

## 4. Layout & shape

- Content width `max-w-[1200px]`, side padding `px-4 sm:px-8`. Header/footer full width.
- Home: hero (headline left, intro + actions right) on a static honey glow
  (`.hero-glow`) → Gantt program → two "label column + content" sections
  (`lg:grid-cols-[4fr_7fr]`). Lists of equal items are rows (`<dl>`), not
  three identical cards.
- Lesson page: sticky left sidebar 300px (`surface`) with the module track,
  content with `<Split>` rows (text left, figure right from `xl` = 1280px).
- Corners: **4px** for sheets/figures/callouts (`rounded-[4px]`), 6px buttons
  and chips (`rounded-md`), 2–3px bars, tiles and diamonds. No pill cards.
- **Tone steps, not lines.** Figures and Callouts have no outline: they sit
  one tone above the page (`surface`, `accent-soft`). No hairline dividers
  inside figures; space separates parts. Outlines stay only for real tables,
  form fields, the Gantt grid, and the selected state of an option card.
- No shadows on things at rest, no glows, no gradient washes. The two
  exceptions are deliberate and static: `.hero-glow` (honey at ~7%) and the
  paper grain on the page ground (`body::before`, ~6% noise, behind content).
- No hairline graph-paper backgrounds (removed in v3).

Controls inside figures:
- **Toggle chips:** `rounded-md px-3 py-1.5 text-sm font-medium press`,
  selected `bg-accent text-accent-foreground`, others
  `bg-foreground/[0.07] hover:bg-foreground/[0.12]`. No outline.
- **Option cards** (bigger choices): `border` kept transparent at rest
  (`border-transparent bg-foreground/[0.04] hover:bg-foreground/[0.08]`),
  selected `border-accent bg-accent-soft`.
- Results and explanations: one `accent-soft` panel with `aria-live`.

Lesson illustrations live in `src/components/lesson/`, registered in
`src/mdx-components.tsx`. Inside a `Figure`, responsive classes use
**container queries** (`@md:`, `@xl:`, `@2xl:`). SVG colors via token
classes (`fill-accent`, `stroke-foreground/60`) or `var(--token)`;
`role="img"` + Ukrainian `aria-label`. Long words in narrow cells:
`minmax(0,1fr)` columns + `hyphens-auto [overflow-wrap:anywhere]`.

## 6. Lesson authoring pattern (MDX)

```mdx
# Lesson title

Intro paragraph (full width, 70ch).

<Split>

## Section heading

Text the illustration explains…

<SomeFigure />

</Split>
```

- Every illustration sits next to the text it explains (inside `<Split>`).
  **The last child of a `Split` is always the figure** (or a Callout): a
  Split without one pushes its last paragraph into the side column. Text
  without a figure goes outside `<Split>`.
- Module opener: `<Split>` with intro + `<Callout title="Після завершення цього модуля ви зможете">`.
- Module closer: `<Split>` with summary + `<Callout title="Ключові висновки модуля">`.
- Long lists without a figure → `<Columns>`.
- «ялинки» quotes, «проєкт» spelling, lowercase after colon in list items.
- Formulas: KaTeX via `remark-math` — inline `$r$`, block `$$ … $$`. Keep each
  block formula short enough for a phone; `.katex-display` scrolls as a
  safety net.
- Lessons are for understanding, not drilling: start from a question or
  example, put formulas in `<FormulaNote>` (collapsed by default) unless the
  author wants them visible. Inside a `FormulaNote`, explain **every symbol**
  in plain words before the formula, and where it helps, add a live
  calculator on the module's example.
- A module's running example with numbers lives in `src/content/examples/`:
  figures import the data and compute values from it, so text, charts and
  calculators never disagree. Check the numbers you quote in MDX against it.
- Interactive figures are client components (`"use client"`) inside a
  `Figure`: visible labels, validated input with an inline message, results
  with `aria-live`, numbers via `Intl.NumberFormat("uk-UA")`. Answer one
  question and say the result in a sentence.
- Every lesson has a `description` in `src/content/course.ts` (≤160 chars):
  search snippet and link-preview text.

## 7. Motion

Curve: `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)` (strong ease-out). UI
feedback stays under 300ms; never `ease-in` on UI.

- **Load:** Gantt bars draw in (`animate-draw`, staggered) and the hero
  marker under «віхи» draws itself once (`.marker-stroke`, 900ms). Nothing
  else animates on load; no fade-in-on-scroll, no hover lifts.
- **Press:** the `press` utility on chips and buttons — colors change in
  160ms and the control scales to 0.97 while pressed.
- **Explanatory loops** inside figures are allowed when they show the idea
  (flow dots in `ProjectAnatomy`, arrows in `MotivationDrivers`).
- Hover = color/background change only, `duration-200` or `press`.
- `prefers-reduced-motion` reduces animation globally (`globals.css`); the
  marker and split-flap then show their final state at once.
- Focus: global 2px honey outline, offset 3px — never remove.

## 8. Copy

Plain verbs, sentence case, no filler. Never show a bare abbreviation:
expand it at first mention in the text *and* on any figure that can be read
on its own (Ukrainian name first, then e.g. «PI (Profitability Index)»).
Buttons say what happens («Почати з модуля 1», «Відкрити програму»). Don't
promise features that aren't built without marking them («Завдання модуля —
скоро»). Never invent testimonials or numbers.

## 9. Pre-delivery checklist

- [ ] Tokens only; checked in **both** themes; one accent for action/selection, sage = progress
- [ ] No eyebrows, no outlines around figures or callouts, no hairline dividers, no assistant palette
- [ ] Headings `font-display`, body Fixel Text; no all-caps labels, no `·` meta, no `→` on buttons
- [ ] 375px, 768px, 1280px, 1440px — `document.documentElement.scrollWidth` equals viewport width
- [ ] Focus visible; UI transitions ≤ 300ms with `--ease-out`; reduced motion respected
- [ ] Text contrast ≥ 4.5:1; meaning never by color alone
- [ ] New lesson: `description` in `course.ts`; its preview image renders (`/modules/<m>/<l>/opengraph-image`)
- [ ] After editing `globals.css` locally: stop dev, `rm -rf .next`, restart (Turbopack may serve stale CSS)
