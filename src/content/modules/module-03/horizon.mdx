<Split>

## Взаємозалежність проєктів

Для вибору правильного інструментарію управління важливо чітко класифікувати проєкт. Особливо цікавою є класифікація за **взаємозалежністю рентабельності**:

- **Взаємовиключні (альтернативні) проєкти**: прийняття одного проєкту зводить рентабельність іншого до нуля (наприклад, будівництво АЕС або вугільної електростанції в одному районі).
- **Умовні проєкти**: рентабельність одного дорівнює нулю без реалізації іншого (наприклад, очисні фільтри та сама вугільна електростанція).
- **Незалежні проєкти**: прийняття одного жодним чином не впливає на рентабельність іншого.
- **Синергетичні проєкти**: рентабельність зростає при спільному впровадженні (наприклад, новий завод та їдальня на його території).
- **Заміщуючі проєкти**: рентабельність одного знижується при прийнятті іншого (наприклад, міст через річку та паромна переправа).

Також варто розрізняти **проєктний аналіз** (проводиться аналітиками для моделювання проєкту та збору даних) та **експертизу проєкту** (здійснюється зовнішньою командою, наприклад банком, для перевірки достовірності розрахунків та прийняття інвестиційного рішення).

## Горизонт планування

Будь-який проєкт обмежений у часі. Загальний **строк життя проєкту** може становити 20–50 років, що робить точний прогноз неможливим. Тому в аналізі використовують умовне поняття — **горизонт планування (розрахунковий строк життя)**. Для його встановлення аналітики спираються на такі індикатори:

1. *Термін служби найдорожчого обладнання* (наприклад, верстат з терміном експлуатації 5 років).
2. *Передбачуваний термін життя продукту на ринку* (період наявності платоспроможного попиту).
3. *Суб'єктивний індикатор* (планований час перебування інвестора у даному бізнесі).
4. *Період достовірності інформації* (критичне правило проєктних аналітиків: «сміття закладеш — сміття отримаєш»).
5. *Термін повернення кредиту* (вимога банків моделювати проєкт на строк до повного погашення боргу).
